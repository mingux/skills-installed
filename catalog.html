How to call them

Every skill is listed here with the exact command. Click a name for its full card.

Type / + the nameAny skill starts on demand: /council --quick …, /prompt-master …. In Claude Code, type / to see the list.
Or just askMost skills start by themselves when your request matches what they do, e.g. "write me a Cursor prompt" starts prompt-master.
On demand onlyMarked manual-only below: the expensive ones (/council, /anatomy), the trading skills and parked skills. They never start by themselves and cost nothing until you type the command.
Agents and workspacesAgents run when you name them ("use the planner agent…"). Workspace skills load only when you open Claude Code inside that folder.
